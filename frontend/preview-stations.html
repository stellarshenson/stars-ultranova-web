Orbital station detail preview - StationDetail

Static page: no game state, no API calls. Every station is a signed distance field sphere traced per pixel at 256 x 256, with soft shadows, ambient occlusion, Fresnel rim, a cool planetlight fill and triplanar surface texture. Each class contributes one scene function built from exact analytic primitives; the raymarcher, the shading and the camera are shared and never branch on a class name. Cameras are off axis in yaw and pitch for every design.

Six classes at render resolution

Detail crops at 3x, smoothing off

The centre of each hull magnified, so the plating seams, the panel drift, the brushed streaking and the occlusion inside the recesses are visible as pixels rather than as an impression.
