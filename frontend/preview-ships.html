Ship hull detail preview - ShipDetail

Static page: no game state, no API calls. Every hull is a signed distance field sphere traced per pixel at 224 x 224 by the shared engine (sdf-engine.js), with soft shadows, ambient occlusion, Fresnel rim, cool planetlight fill and triplanar plating. Every design is a data record - a declarative part list one generic evaluator walks - never a hand-written scene function. Cameras are off axis in yaw and pitch for every hull, yaw varied across the sheet. Design language per docs/ART_DIRECTION.md: The Expanse crossed with W40k.

Thirty ship classes at render resolution

Capital detail crops at 2x, smoothing off

The best capitals magnified: plating seams, armour bands, gun-port rows, buttress arcs and the occlusion inside the recesses visible as pixels rather than as an impression.
